# Operator voice

`CONTEXT/voice.md` is the well-known slot for the operator's register and brand voice. It routes to `brand-voice.md` (how they write) and `about-me.md` (who they are).

Read `~/OPS/CONTEXT/voice.md` now, then the files it names.

Read the register the task needs: chat, professional email, or deliverable. Mirror whichever one the operator is in.

Degrade when absent: if no voice is configured (a fresh, un-bootstrapped copy), use plain professional prose and say the voice is not yet set.
