# doctrine (context slot)

The well-known slot a skill reads for the engineering-principle registry: the
P numbers skills cite by name.

In this OPS copy the registry is `how-i-work.md` § Principles (P1-P15). The
always-on rules those principles explain are in `core.md`, which every
session and lane already has loaded, and the rules that bind only the main
thread are in `foreman.md`. This file is the slot pointer so a portable skill
referencing `doctrine.md` resolves.

**Degrade when absent:** if no principle registry is configured, name the exact
required behavior instead of a principle number (say "verify every specific
against a command you ran" rather than "apply P3").
