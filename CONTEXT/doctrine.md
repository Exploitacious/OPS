# doctrine (context slot)

The well-known slot a skill reads for the engineering-principle registry — the
P/F numbers skills cite by name.

In this OPS copy the registry lives in `operating-doctrine.md` (the universal
principles P1-P15) and `fleet-doctrine.md` (the F-rules for multi-agent
coordination). This file is the slot pointer so a portable skill referencing
`doctrine.md` resolves.

**Degrade when absent:** if no principle registry is configured, name the exact
required behavior instead of a principle number (say "verify every specific
against a command you ran" rather than "apply P3").
